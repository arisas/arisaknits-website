Hello! The website is now fully migrated to Astro, and thanks to Burton, the blog is fully up and running again!

Right now, I have to set up the pages manually each time there's a new pattern release, but I'm planning to work the patterns page so that it's set up similarly to the Blog pages where I can use [Content Collections](https://docs.astro.build/en/guides/content-collections/) and have each pattern as a Markdown.

## Big Walk Crochet Doll Pattern release!

![Big Walk crochet doll](../../assets/bigwalkdollphoto.png 'Big Walk crochet dolls')

My second ever pattern is out and it's FREE! You can find the pattern [here](/patterns/bigwalkcrochetdoll). I had such a memoriable time playtesting [Big Walk](https://bigwalk.game/) with my team while I was at Panic that I crocheted them all dolls of their characters from the game (I cried because I didn't want the game to be over!). This was months ago, but I finally found time (motivation, really) this week to clean up the instructions and release it for anyone to make :)

I do have some more props I'm working on like the flaregun and matching blocks that I plan to update the pattern with. Maybe I'll figure out how to write instructions for the backpack too -- sewing it to the doll was a bit tedious, though that I don't know if I can translate it into a pattern.

Hope you like it!
